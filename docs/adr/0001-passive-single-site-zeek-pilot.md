# Start with a passive, single-site Zeek pilot

**Accepted.** Pilot execution and validation are pending.

SentinelAI's first operational milestone is a supervised, passive Zeek monitoring pilot at one site, the existing isolated and authorized lab. Keep the lab isolated, and obtain explicit approval before connecting to any real external network. Size the pilot to its current needs and revisit multi-site deployment when operating evidence establishes the requirements.

G36 demonstrated continuous ingestion using authorized recorded replay. The pilot will establish evidence for live sensor handoff and log rotation in the controlled lab. Staying with replay alone would leave the live handoff untested. Starting with multiple sites would add infrastructure and broaden the authorization scope before that path is verified. Claims about detection efficacy, production capacity, and broader deployment readiness require separate evidence.
